VIBRATION LAB — PORTABLE EDITION

Open Vibration-Lab.html in Microsoft Edge or Google Chrome.
All seven labs are in this one file. You do not need Node.js, npm, a local
web server, package downloads, or an account to view the demos.

Keep the file extension .html. Use the lab links inside the page to navigate.
Reference links can open external websites; they are not needed to run the labs.

The browser needs JavaScript and WebGL. If company policy blocks local HTML
files or WebGL, ask IT for approved internal hosting or browser support.

Verification: all seven demos were checked through an HTTP preview of this
self-contained file. Direct opening via file:// and Windows execution were
not tested by the build environment.

Developers: regenerate using npm run build:portable in experiences/vibration-lab.
