Method, assumptions & interpretation

Each oscillator is integrated once across the full flight. Display windows never reset states or change the qualification duration.

z̈ + 2ζωₙż + ωₙ²z = −abase
Absolute acceleration: −2ζωₙż − ωₙ²z. Pseudo acceleration: ωₙ²z. Both sides use the selected convention, Q and natural-frequency grid. Whole-record absolute acceleration maximax is the matching acceleration SRS.

Exact state transition for piecewise linear input (first-order hold); sampled output peaks. Display bins are 50 ms; time readout marks the bin end and windows include completed bins. Initial state is zero. Imported anti-alias filtering and prehistory are unknown; offsets are retained. No real flight conclusion, fatigue assessment, qualification certification, or safety verdict follows.
